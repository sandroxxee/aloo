# CONTEXTO DO PROJETO

## IDENTIDADE
- **Nome do Projeto**: ASSET INTELLIGENCE
- **Categoria**: Plataforma SaaS Enterprise de Inteligência Comercial.
- **Objetivo Principal**: Encontrar oportunidades reais de negócios no mercado brasileiro, conectar compradores e vendedores e automatizar prospecção comercial utilizando IA.
- O sistema **NÃO é apenas um minerador de contatos**. Ele deve evoluir para um **Radar Nacional de Oportunidades Comerciais**.
